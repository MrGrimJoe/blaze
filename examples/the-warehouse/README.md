# The Warehouse

A one-minute animated short, made with [Blaze](../..) and CDRCA. **This folder is the video's own project.** The
tool (Blaze, CDRCA) lives in its own repository and contains nothing from this video.

```
story.txt                    the screenplay (the source of everything below)
the_warehouse.blaze/         the Blaze project built from it
  scenes/*.cdrca             the video's CDRCA code: one script per scene (plain CDRCA, edit these)
  assets/                    the images those scripts use (generated characters and backdrops)
  audio/                     the voice lines (espeak-ng)
  project.json               scene list, timings and subtitles
the_warehouse.mp4 / .srt     the rendered output (960x540, 20 fps)
```

## Rebuild the video

You need the tool installed (see its README): `python ../../blaze.py setup` once.

```
# from the screenplay (regenerates art + voices, rewrites the_warehouse.blaze):
python ../../blaze.py make story.txt -o the_warehouse.mp4 --res 960x540 --fps 20

# or re-render only, after editing scenes/*.cdrca by hand:
python ../../blaze.py build the_warehouse.blaze -o the_warehouse.mp4 --res 960x540 --fps 20
```

Characters (JOHN, MARY, TIM) and backdrops are generated by the tool. To use your own, put them in `library/characters/` and
`library/backdrops/` next to `story.txt` and point the screenplay at them (`CAST: JOHN = asset:john`, `BACKDROP: name`).

## Notes

- The `[CAMERA ...]` and `[WEATHER ...]` commands in `story.txt` are skipped by the tool for now (CDRCA has no camera or
  weather yet), so the rain and storm are only suggested by the backdrop colours.
- `the_warehouse.blaze/` is generated: deleting it and running `make` recreates it.
